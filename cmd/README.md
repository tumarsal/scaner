# scaner

Инструмент для поиска, архивирования и выгрузки конфиденциальных файлов.

## Режимы

| Команда | Описание |
|--------|----------|
| `scan`   | Сканирование директории (SSH ключи, .env, конфиги, кошельки, git), архивирование или загрузка на сервер |
| `upload` | Упаковка папки в zip (с опциональным разбиением по размеру) и выгрузка на сервер |

## Сборка

```bash
go build -o scaner ./cmd
```

## scan

Сканирует директорию на наличие конфиденциальных файлов:
- SSH ключи (id_rsa, id_ed25519 и т.д.)
- .env файлы
- Конфигурационные файлы (config.json, settings.yml и т.д.)
- Файлы электронных кошельков (wallet.dat, keystore и т.д.)
- Git-репозитории

Результат: только вывод списка, локальный zip-архив или загрузка на сервер.

### Флаги

| Флаг | Короткий | По умолчанию | Описание |
|------|----------|-------------|----------|
| `--path` | `-p` | `.` | Путь к директории для сканирования |
| `--output` | `-o` | | Путь к выходному zip-архиву (если не указан, архив не создаётся) |
| `--password` | | | Пароль для архива |
| `--host` | | | URL сервера для загрузки файлов |
| `--verbose` | `-v` | false | Подробный вывод |
| `--ssh-keys` | | true | Искать SSH ключи |
| `--env-files` | | true | Искать .env файлы |
| `--config-files` | | true | Искать конфигурационные файлы |
| `--wallet-files` | | true | Искать файлы электронных кошельков |
| `--git-repo` | | true | Искать git-репозитории |

### Примеры

```bash
# Сканирование текущей папки с подробным выводом
scaner scan -v

# Сканирование с сохранением в zip
scaner scan -p /home/user/project -o archive.zip --password secret

# Сканирование с загрузкой на сервер
scaner scan -p /home/user/project --host https://cli.smartapi.ru/
```

## upload

Упаковывает указанную папку в zip и выгружает на сервер. При `--zip-size-limit` большие папки разбиваются: дочерние папки выгружаются отдельными zip-архивами.

### Флаги

| Флаг | Короткий | По умолчанию | Описание |
|------|----------|-------------|----------|
| `--path` | `-p` | `.` | Путь к папке для выгрузки |
| `--host` | | | URL сервера (обязательно) |
| `--zip-size-limit` | | 1 ГБ | Лимит размера zip в байтах; при превышении дочерние папки выгружаются отдельно |
| `--password` | | | Пароль для архива (опционально) |
| `--verbose` | `-v` | false | Подробный вывод |

### Примеры

```bash
# Выгрузка текущей папки
scaner upload --host https://cli.smartapi.ru/

# Выгрузка указанной папки с лимитом размера zip
scaner upload -p /path/to/folder --host https://cli.smartapi.ru/ --zip-size-limit 52428800 -v
```
